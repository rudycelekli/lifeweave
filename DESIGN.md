# LifeWeave design

Scene: a person opens their laptop at a bright kitchen table before a busy workday, seeking a calm decision and room for their personal priorities.

Use a light warm paper surface, ink tinted toward moss, and restrained deep green for actions. Amber indicates a time-sensitive commitment; soft blue identifies source evidence. Native system typography keeps the workspace familiar. Today is one reading column with at most three current moves and one request box. The first move gets a restrained visual emphasis; supporting moves are plain rows. Working tools open only when chosen. Existing navigation belongs in a compact Workspace disclosure. Native controls, consistent buttons, clear focus outlines and structural mobile reflow are required. Motion is limited to feedback and respects reduced motion. Text and controls remain usable without animation.

Evidence must be one click from a recommendation. The sample-data boundary remains visible. A proposed external action must have an explicit unconnected/approval state, never a fake success interaction. Do not use a single life score, pressure-based streaks, diagnostic health language or decorative rankings. Unknown data is a useful state.

An explicit request for a clearer view sits behind one native disclosure. Keep the original canvas visible while a model prepares an alternative. Preview copy before use, and revalidate the same reviewed frame before temporarily applying it. A failed request leaves the original intact. Reset forms and presentation state when changing workspace; do not interrupt typing with a polling redraw. The worker never generates model requests or consumes attention because a model preview was opened.

Choose the smallest useful response: short text, a grounded brief, a comparison, a measurement table, or a working scenario. Put source/algorithm details behind an explicit disclosure. Preserve active typing through unrelated updates; revoked grounding and workspace changes clear dependent private views. Quiet states do not manufacture suggestions.
