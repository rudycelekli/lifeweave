# Hark design reference

Observed 2026-10-13. [Hark's chat](https://hark.com/chat) redirected to sign-in. No authenticated account, private conversation, payment, or computer-use workflow was accessed.

The [public product page](https://hark.com/) describes a persistent chat with Projects, suggested action buttons, custom Panels, and an isolated computer-use service. These are vendor descriptions, not independently validated capabilities. Its Panels and prioritization support the user's requested direction: context-specific working tools that appear proactively, with brief clarification when human input changes a decision.

LifeWeave implements a focused dashboard instead of requiring a chat prompt. A short opportunity list selects a declarative evidence-linked canvas. Focus windows include a live bounded calculator and editable local drafts. Detailed evidence, suppression reasons, connector states and preferences are revealed progressively. An optional collapsed request control asks a host-configured model for clearer wording or a rearranged view, previews it without replacing the original, and fresh-validates before explicit temporary use. No pixels, private UI or proprietary code from Hark were copied.
