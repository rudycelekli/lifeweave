# Open local foundation and commercial services

The personal local edition is fully open source under Apache-2.0. Local goals, evidence, storage, proactive evaluation, UI, exports and custom integrations work without a license server. No remote kill switch, subscription check or paid API is required for those features. Community-built connectors may use the same public interface.

Optional personal premium connections can sell maintained OAuth setup, provider partnerships, reliable token renewal, managed ingestion, mobile push delivery and support. Provider charges and model usage must be visible and separate. A premium service may have commercial terms, but ownership and export of local user data stay with the user. These services are planned; this build has no billing, paid entitlement, or connected premium provider.

Enterprise offerings can provide workspace administration, SSO/SCIM, roles and source-sharing policy, managed encrypted storage, audit export, fleet operations, service guarantees, approved business integrations and deployment support. Optional management, operational telemetry, websites and marketing packs should share the same domain contracts. Every side effect still needs a host-owned capability and authorization. Buying a plan does not grant an agent authority.

The personal UI is the starting product. Business expansion should follow demonstrated repeat usefulness and willingness to pay. Avoid duplicating a generic CRM, website builder or marketing suite before a specific workflow and connector have qualified. Public source does not promise premium-provider resale rights; each provider agreement requires separate verification. Exact prices, billing vendor and packaging are undecided.
