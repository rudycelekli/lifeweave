# Qualification roadmap

## Implemented local alpha

Portable goal/evidence engine; five proactive rule families; six declarative block types; bounded working scenarios; DOM/Web Component/React renderer; local personal and business states; explicit imports and measurements; shared goal/person/project context; single-question missing-fact confirmation; deterministic requested focus views; evidence-linked outcome ledger; saved local drafts; feedback/quiet-hours/attention receipts; optional explicit model request/preview/review; read-only provider contracts; seven pinned source reviews; macOS local shell source. Evidence is in docs/evidence and package tests.

## Next acceptance gate

Connect one real read-only email/calendar provider with least-privilege OAuth, token renewal, bounded pagination, source freshness, connect/read/revoke canaries and audit receipts. Qualify an explicit local model against frozen layout/fact-preservation and user-usefulness fixtures; the current small installed model's one invalid proposal was rejected. Review inferred commitments before activation. Record useful/irrelevant/harmful outcomes and human oversight; do not treat clicks, model explanations or a high test count as user success.

## Personal premium connections

Qualify maintained managed provider connections, notifications and native mobile bridges. HealthKit needs a native consented companion. Prototype premium entitlement without withholding local data export or the public connector contract. Validate paid-provider licensing, user willingness to pay, operating cost, support burden and revocation before charging. Prices are not set.

## Business foundation

Add organization membership, least-privilege roles, owner accountability, purpose-scoped source sharing, immutable audit, retention and encrypted multi-user storage. Prove isolation using adversarial tests and independent review. Then qualify a narrow business workflow such as customer follow-through or capacity planning.

## Optional business capability packs

Management and operational telemetry; customer and revenue pipelines; website creation and maintenance; marketing research and campaign preparation. Each pack declares observation schemas, surfaces, required scopes, write actions, cost ceilings and rollback. External publishing, spend and campaign sends remain independently authorized. Private personal data is excluded by default.

## Distribution and outcome proof

Notarized and signed macOS releases, cross-platform desktop binaries, native mobile clients and safe update channels require separate build and acceptance receipts. Measure recommendation precision, time to useful action, interruption burden, real goal evidence, latency, total cost and human oversight against a simple baseline. Longitudinal effectiveness and competitive superiority are unproven.
